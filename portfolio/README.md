# `portfolio/` folder

This folder makes the repo appear as a card on
[banjobyster.github.io](https://banjobyster.github.io). The site reads these
files directly from GitHub at page load. Nothing here affects the project's own
code or build.

| File | Purpose |
|---|---|
| `project.json` | The card data |
| `cover.svg` | The card image |

`vibeCoded` is `true` on this project, so the card carries the vibe coded
disclosure chip and sorts after the hand written projects.
